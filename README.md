## Установка и запуск

Требуются Python >= 3.12 и uv, для разработки также необходим ruff.

```bash
git clone https://github.com/alvassin-mephi/project2_vasin_m26_555.git
cd project2_vasin_m26_555
uv sync
uv run database
```

Другие варианты запуска:

```bash
uv run project
uv run python -m primitive_db.main
```

Все три команды запускают одно приложение. Ручная активация `.venv` не требуется.

## Проверка и сборка

Выполните из корня проекта:

```bash
uv run ruff check .
uv build
uvx twine check dist/*
```

## Установка готового приложения

После сборки можно установить пакет как отдельный инструмент:

```bash
uv tool install --force dist/primitive_db-0.1.0-py3-none-any.whl
database
```

Если команда не найдена, выполните `uv tool update-shell` и откройте новый терминал.
Для проверки установленного инструмента используйте терминал без активной `.venv`.

`uv run database` запускает текущий код проекта, а `uv tool install` устанавливает
отдельную копию собранного пакета. Для её обновления повторите сборку и установку.

## Команды

Команды вводятся внутри приложения после запуска `uv run database`.
Ниже приведены примеры отдельных команд и их вывода, а не последовательный сценарий.
Время выполнения может отличаться от указанного в примерах.

### Общие команды

#### `help`

Показывает справку по всем доступным командам.

```text
Введите команду: help

***Процесс работы с таблицей***
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
...
```

#### `exit`

Завершает работу приложения без дополнительного сообщения.
Сохранённые таблицы и записи остаются на диске.

```text
Введите команду: exit
```

### Управление таблицами

#### `create_table`

Создаёт таблицу с указанными столбцами. Каждый столбец задаётся как `имя:тип`;
поддерживаются типы `int`, `str` и `bool`. Столбец `ID:int` добавляется автоматически первым.

```text
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

#### `list_tables`

Показывает имена всех созданных таблиц.

```text
Введите команду: list_tables
- users
```

#### `drop_table`

Удаляет таблицу вместе с её данными. Для подтверждения удаления введите `y`
в ответ на запрос; любой другой ответ отменяет операцию.

```text
Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```

### CRUD-операции

Примеры используют таблицу `users` из примера `create_table`.
Строковые значения указываются в кавычках, числа и `true`/`false` — без кавычек.
В `where` и `set` поддерживается одно равенство.

#### `insert`

Добавляет запись. Значения передаются в порядке столбцов таблицы;
все поля обязательны, кроме автоматически создаваемого `ID`.

```text
Введите команду: insert into users values ("Sergei", 28, true)
Функция insert выполнилась за 0.000 секунд
Запись с ID=1 успешно добавлена в таблицу "users".
```

#### `select`

Выводит все записи или только записи, соответствующие условию `where`.

```text
Введите команду: select from users
Функция select выполнилась за 0.000 секунд
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

#### `update`

Обновляет поле во всех записях, соответствующих обязательному условию `where`.
Новое значение должно соответствовать типу столбца. Изменять `ID` нельзя.

```text
Введите команду: update users set age = 29 where ID = 1
Запись с ID=1 в таблице "users" успешно обновлена.
```

#### `delete`

Удаляет все записи, соответствующие обязательному условию `where`.
Если записи найдены, запрашивает подтверждение: `y` разрешает удаление,
любой другой ответ отменяет его.

```text
Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
```

#### `info`

Показывает имя таблицы, её столбцы с типами и количество записей.

```text
Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 1
```

## Хранение данных

Схемы таблиц сохраняются в `db_meta.json`, записи — в `data/<имя_таблицы>.json`.
Оба пути отсчитываются от текущего рабочего каталога. Данные доступны после
перезапуска приложения из того же каталога.

## Декораторы и кэш

- Ошибки ввода и операций с базой выводятся сообщениями, после которых можно ввести следующую команду.
- `drop_table` и `delete` запрашивают подтверждение: только `y` разрешает удаление, любой другой ответ, включая Enter, отменяет его.
- Успешные вызовы `insert` и `select` выводят время выполнения с точностью до трёх знаков после запятой.
- Результаты `select` кэшируются по имени таблицы и условию `where` в пределах одного запуска. Повторный запрос использует кэш и не выводит время выполнения `select`.

Кэш сбрасывается после успешных `create_table`, `insert`, `update`, `delete` и `drop_table`.
